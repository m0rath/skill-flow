# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussion about the work. Harassment, insults and personal attacks aren't tolerated in issues, pull requests or any other project space.

To report a problem, contact the maintainers privately through [GitHub](https://github.com/m0rath). Reports are handled confidentially. Maintainers may remove content, or block people who break these rules.
